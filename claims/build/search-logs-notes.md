# Search logs for absence rows: build notes (2026-10-24)

File-only subagent run. No web or PubMed search was done. Every string, ID, count and screening figure in `claims/build/search-logs.csv` is copied from the project files named in each cell. `claims/claims.csv` and every other existing file were not edited. Status: draft, not reviewed by a skeptic.

## Scope
Rows taken: every row in `claims/claims.csv` whose claim_id starts with `ABS-`, `UC-ABS-` or `UC-GAP-`, plus every other row with kind `absence`. That is 81 rows: 22 ABS, 21 UC-ABS, 26 UC-GAP (4 of them kind `finding`: UC-GAP-01, -08, -15, -26) and 12 GL rows of kind `absence` (GL-02, -04, -10, -12, -13, -17, -23, -24, -25, -37, -39, -44).

Files searched: `analysis/` (evidence-searcher Set A and Set B in `analysis/subagent-runs/`, clinical-chemist both runs and round 2, biostatistician, scientist, endocrinologist, pcp), `reviews/` (steelman, skeptic-steelman, skeptic-new-roles both sets, skeptic-merged, skeptic-usecases, scope-audit, skeptic-cardiology, skeptic-specialties, and the six specialty reviews), `usecases/reviewers/` (hypo-pancreas = H, classification-paeds = C, metabolic-liver-ir = M) and `update-watch/` (dry-run and runs files; none held a search behind these rows). There is no `subagents/` folder at the project root; the Set B files are under `analysis/subagent-runs/` and `reviews/subagent-runs/`.

## Limits on how the cells were built
- Screening figures are what the files state. Set A screened "the top 8-12 records" of large sets (round 2: top 25-40, or all records of sets under about 40); Set B "titles of the top 3-25 hits"; the steelman "the top 5-10 titles". Where a cell gives only a count, the file states no screened number.
- Some links between a claim and a search are mine, from matching topic terms (for example, ABS-04 to the hepatology and nephrology insulin-clearance strings, and ABS-21 to the interaction strings). Where the file does not tie a string to the claim, the cell says "related" or "closest recorded string". UC-ABS-02 (HAIR-AN) has no direct string.
- `analysis/evidence-searcher.md` section 12.1 Request 3 says TyG repeatability was searched with "10 strings"; Appendix C shows 5 TyG-labelled strings (R2-3d, -3h, -3i, -3j, -3k). The cell copies both.
- Set B string S066 (grep of ADA 2026 s3, PMID 41358891) returned 0 sentences although Rec 3.13 contains "insulin resistance"; Set B records that the PMC copy held only about 3k characters. It is a failed retrieval, not a negative.

## Absence claims that a recorded search contradicts or weakens
1. **ABS-12** (no baseline HOMA-IR interaction in the CV outcome trials). `reviews/subagent-runs/skeptic-new-roles.md` S1: a simpler statin and IR subgroup string returned 13 records, one of them PMID 42291078 (ODYSSEY OUTCOMES, 11,837 patients), an IR-stratified analysis of a PCSK9-inhibitor CV outcome trial. The skeptic notes it is not a clean treatment-by-IR test and the measure is "not determinable" (`reviews/scope-audit.md`). The claim's "not found in the screened records" wording should name it.
2. **ABS-10** (no decision-curve analysis). Steelman P2 (145), P3 (27) and P4 (71) found decision-curve papers for IR indices (titles only). The deliverable already states this; the original searcher negative stands only as "no DCA of the decision to measure".
3. **ABS-11** (no delta-C study over PREVENT, SCORE2 or PCE). ATTICA (PMID 41178693; TyG over SCORE2) was found by Set B (S103) and in the steelman's work. The claim already notes it; the absence holds only for fasting insulin and HOMA-IR, not TyG.
4. **UC-ABS-16** (M's summary of ADA Rec 3.13 "with no mention of insulin resistance"). `reviews/skeptic-usecases.md` section 2 item 1 (raw PMC HTML) and `analysis/evidence-searcher.md` section 5.1 (PMC12690170 FT-scan) both record that Rec 3.13 says "evidence of insulin resistance and prediabetes". The recorded text contradicts the summary. The deliverable lists this as a conflict; the ledger row should show it as resolved against the summary.
5. **UC-GAP-04** (analogue cross-reactivity by manufacturer not retrieved, H). `analysis/evidence-searcher.md` round 2 (R2-4b 51, R2-4c 206, R2-4d 4; section 12.1 Request 4) and `analysis/clinical-chemist-round2.md` section 2 report analogue cross-reactivity by named platform (Heurtault 2014, 16 assays, 0-264%; Violin 2023, Cobas vs Architect and Access; Li 2025, Atellica; all abstract level). The gap is real for H's own run but not for the project. Proinsulin cross-reactivity on named current platforms is still not retrieved (ABS-06).
6. **Retrieval gaps that another role closed** (not absence-of-evidence contradictions, but the "could not retrieve" wording is out of date for the project): UC-GAP-05 and UC-GAP-06 (ADA 2026 s2 and s14: Set A FT-scanned both), UC-GAP-18 (ADA 2026 s2, s4, s8: Set A full text), UC-GAP-19 (AACE 2022: `reviews/skeptic-usecases.md` full XML), UC-GAP-20 and UC-ABS-15 AASLD half (whole AASLD searched, `reviews/skeptic-usecases.md` section 2.4 item 3; same as GL-44), UC-GAP-21 (verbatim reads by the use-case skeptic), UC-GAP-24 (CTRI, ISRCTN and IRCT pages read in Set B M26), UC-ABS-10 KDIGO half (`reviews/specialty-nephrology-2026-10-24.md` L20), UC-GAP-12 (four first-trimester cohort abstracts later read, `reviews/specialty-reproductive-2026-10-24.md` #1). UC-ABS-05 (Igls threshold half) is already marked half superseded in the ledger.
