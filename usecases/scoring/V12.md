## Reasoning in brief
- Rows 1, 2, 24: the hypoglycaemia pathway is specialist-owned (timed sample at documented hypoglycaemia). Row 1 gets D1 4 because endogenous hyperinsulinism cannot be established without the measurement (Endocrine Society 2009; ENETS 2016). Rows 2 and 24 get 3 because history, antibodies, BOHB or glucagon response partly substitute. Stakes 3 for all three: untreated or misdirected hypoglycaemia causes serious morbidity.
- Row 22: invasive, referral-centre procedure; low D5 and D6, moderate stakes because the diagnosis is already known.
- Row 23: provoked-hypoglycaemia OGTT; weakest evidence base in the group (single-centre data quoted in ENETS); false positives are plausible.
- Row 29: C-peptide is a labelled eligibility criterion (FDA Tzield label, rev 06/2026, via project file), so D1 4. Stakes 1 under the "default is no drug" reading (2 if the default were untested treatment); the benefit is a surrogate.
- Row 33: needle-free home urine test is low burden, but results only prompt reclassification work-up (antibodies, genetics), so D1 2; stakes moderate (years of unneeded insulin).
